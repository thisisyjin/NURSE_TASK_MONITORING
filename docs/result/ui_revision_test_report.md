## 자동 테스트와 빌드

명령은 프로젝트 루트에서 실행했다.

`npm test`

```
Test Files  3 passed (3)
Tests  28 passed (28)
Duration  414ms
```

포함 파일은 기존 F2 통합 테스트와 artifact 도메인 테스트다. F2 테스트를 삭제하거나 기대값을 바꾸지 않았다. artifact 테스트는 확인중, 배정 차단, 초기 알림 구성을 새 정책으로 바꿨다.

`npm run build`

```
tsc --noEmit && vite build
✓ built in 560ms
dist/assets/index-CiTdZBU-.css   10.18 kB
dist/assets/index-Ct8qCvEg.js   263.64 kB
```

Node.js 20.18.0에서 Vite가 20.19+ 또는 22.12+를 권하는 경고가 났다. 빌드는 성공했다.

## 이번 브라우저에서 다시 실행하지 않은 것

간호요구 급증, CPCR 발생, A-plus 합류는 버튼을 누르지 않았다. 급증과 CPCR의 기존 단위 테스트는 28건 안에 들어 있다. 발표 주 동선은 지원 추천이라 이 버튼은 P2로 남겼다.

본인 배정과 높음 단계 배정 차단은 후보 목록에 없어서 클릭할 수 없었다. 같은 조건은 `본인, 높음, 이미 배정된 대상에는 지원을 넣지 않는다` 단위 테스트가 통과했다.
