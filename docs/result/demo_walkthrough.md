# 1~2분 발표 동선

시작 주소는 개발 서버의 로컬 주소다. 이번 검증은 `http://localhost:5175/` 였다. 데이터는 가상 데이터이고, 추천은 업무량 규칙이다. 인공지능이 연결되어 있다고 말하지 않는다.

시작 전에 `시연 제어`를 열고 `초기화`를 눌러 09:00으로 맞춘다. 확인 문구가 나온다.

## 1. 시작 화면

말할 내용: 지금 높음은 2명이고, 근무조 업무량은 256분으로 인력 기준 250분을 넘는다.

화면:

- 시계 `09:00`
- 김서연 `담당 업무량 127분`, 수행 대기 6건, 가장 오래 대기 40분, KTAS 2 1명
- 오른쪽 `지원 간호사 추천 2건`
- 김서연과 이하은 모두 추천 1순위 `한지호`, 근거는 여유, 0분, 다른 지원 없음

## 2. 다른 후보를 고르고 배정

김서연 카드의 `다른 지원자 지정`에서 `최민준`을 고른다. 근거가 `담당 업무량 11분`으로 바뀌고 버튼이 `배정 요청: 최민준`이 된다.

버튼을 누른다.

기대:

- 김서연 영역이 `응답 대기`
- 담당 업무량은 아직 127분
- 최근 지원 활동에 `최민준에게 김서연 지원 배정 요청, 응답 대기`

## 3. 간호사 화면에서 수락

`최민준 화면에서 응답`을 누른다. 현재 화면이 `간호사: 최민준`으로 바뀐다.

`수락`을 누른다.

기대:

- `김서연 지원 중`
- 김서연 담당 업무량 76분 근처. 127분의 60%라 76분
- 김서연 환자에 `최민준 수행` 버튼
- 동료 환자의 처방 목록은 보이지 않음

거절을 보여 주려면 초기화 후 한지호에게 이하은을 배정하고, 한지호 화면에서 `거절: 휴식`을 누른다. 리더로 돌아오면 이하은의 다음 1순위는 최민준이다.

## 4. 수행과 종료

지원 중 화면에서 처방 하나의 `최민준 수행`을 누른다. `수행 1건`과 최근 활동의 수행자가 최민준으로 바뀐다.

`지원 종료`를 누른다. 진행 표시는 사라지고 종료 기록은 남는다.

## 5. 확인중을 짧게 보여 줄 때

리더 화면에서 수혈(PRBC)의 `확인중`을 누른다.

기대:

- 처방은 `확인중 09:00`으로 남음
- 수행 대기 건수와 최장 대기에서는 빠짐
- 담당 업무량 127분은 유지
- `대기로 복귀`를 누르면 다시 `대기 40분`

## 6. 마무리

`+15분`은 상단에 항상 있다. 대기 중인 처방의 경과 분만 늘어나고, 확인중 건수는 대기 건수에 들어가지 않는다. 이 버튼은 기존 시연 엔진이라 환자 상태 변화도 함께 일어날 수 있다.

기준이 필요하면 하단 `시연 기준 안내` 또는 `처방 분류 기준`을 연다. Escape나 닫기로 돌아온다.

다시 시작하려면 `시연 제어`의 `초기화`를 누른다.
