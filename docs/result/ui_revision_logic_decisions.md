# UI 2차 개편 로직 결정

새 임상 기준을 만들지 않았다. 화면에서 빼기로 한 값만 표시와 알림 조건에서 제외했다.

## 확인중

상태 값은 `pending`, `acknowledged`, `completed`다. 기존 데이터에 상태가 없으면 `pending`으로 본다.

| 동작 | 결과 |
|---|---|
| 확인중 | 처방을 지우지 않는다. 발생 시각 `at`은 유지하고 `acknowledgedAt`에 시연 시각을 넣는다 |
| 활성 대기 | `pending`만 수행 대기 건수, 최장 대기, 구역 대기 건수에 넣는다 |
| 담당 업무량 | `completed`가 되기 전에는 표준 소요시간을 합계에 남긴다. 확인중도 포함한다 |
| 대기로 복귀 | 다시 `pending`. `at`은 그대로라 경과 분이 이어진다 |
| 수행 | 확인중과 대기 모두에서 가능하다. 완료로 바꾸고 수행자를 기록한다. 같은 처방을 다시 수행해도 건수가 늘지 않는다 |
| 지연 알림 | 확인중 처방은 지연 집계에 넣지 않는다. 이번 개편에서는 지연 건수 자체를 알림 단계에 쓰지 않는다 |

09:00에 김서연의 수혈(PRBC)을 확인중으로 바꾸면 담당 업무량은 127분이고, 수행 대기는 6건에서 5건, 최장 대기는 40분에서 35분이 된다. 1구역 확인중은 1건이다.

## 지원 추천과 상태

후보는 다음을 모두 만족해야 한다.

- 지원 대상 본인이 아니다.
- 이미 다른 지원을 진행 중이거나 응답 대기 중이 아니다.
- 업무 단계가 높음이 아니다.
- 지원 우선 대상이 아니다.
- 같은 대상에 대해 이전에 거절한 적이 없다.

순서는 여유를 보통보다 먼저 두고, 같으면 담당 업무량이 적은 순이다. 09:00 1순위는 환자 없는 한지호, 담당 업무량 0분이다. 박도윤은 우선 대상이라 후보에서 빠진다.

화면에 보이는 근거는 이 계산에서만 가져온다.

- 현재 단계
- 담당 업무량 N분
- 현재 다른 지원 없음

후보가 없으면 `지금 배정 가능한 지원자가 없습니다`.

| 상태 | 화면 | 업무량 |
|---|---|---|
| 배정 요청 | 리더 카드는 `응답 대기`. 같은 대상에 두 번째 요청은 막는다 | 감산 없음 |
| 수락 | 대상과 지원자 카드에 지원 중 표시. 지원자는 대상 처방을 `이름 수행`으로 처리 | 기존 계수 `max(0.35, 1 - 0.4 × 지원 수)` |
| 대리 수행 | 수행자와 지원 건수가 기록에 남음 | 완료된 표준 소요시간만 합계에서 빠짐 |
| 종료 | 진행 표시 해제. 기록은 남음. 같은 시각에 끝나면 기존 최소 지원시간 5분을 기록에 표시 | 감산 해제 |
| 거절 | 사유는 휴식, 중증 환자 전담, 다른 업무. 그 간호사는 그 대상의 다음 추천에서 제외 | 감산 없음 |

차단은 화면 목록과 `assignmentBlockReason` 양쪽에서 한다. 본인 배정, 높음 단계, 이미 응답 대기인 대상은 상태가 바뀌지 않는다. CPR 팀 배정은 기존처럼 긴급 자동 수락이라 이 대기 흐름을 타지 않는다.

09:00에 한지호가 이하은 지원을 거절하면 이하은의 다음 1순위는 최민준이다. 김서연 쪽 후보는 한지호를 그대로 둔다. 거절은 대상별로만 제외한다.

## 알림에서 뺀 것

이전 초기 알림은 인력 3단계, 김서연의 지연 기반 2단계, 이하은 1단계, 그리고 예측 0단계였다.

지금은 다음만 만든다.

- 인력 기준 초과: 3단계. 09:00은 256/250이라 유지
- 직접 `지원 필요` 또는 업무 단계 높음: 1단계
- 높음이 30분 이상 지속: 2단계
- 열린 급증 또는 CPCR: 기존처럼 해당 간호사를 높음으로 두고 별도 긴급 알림

09:00의 김서연과 이하은은 높음이 막 시작된 상태라 1단계다. 1구역에 목표시간을 넘긴 처방이 있어도 그 건수로 2단계를 만들지 않는다. 예측 알림은 만들지 않는다.

`dueOf`와 우선 대상의 10분 앞당김은 계산 함수에 남아 있다. 기본 화면과 이번 알림은 그 값을 확정 지표처럼 보여 주지 않는다.

## 업무량 숫자는 유지

관찰, 활력, 미완료 처방 표준시간 합계와 단계 경계 30분, 50분은 그대로다. 정확히 50분은 보통이다. 급증이 있으면 합계와 관계없이 높음이다.

1시간 뒤 값은 `loadOf` 안에서 계속 계산되지만 카드, 막대, 문구에 표시하지 않는다.

인력 적정성은 담당 환자가 있는 간호사 수 × 50분이다. 09:00은 5 × 50 = 250, 합계 256, 초과다. 라벨은 `시연 기준`이다. 환자 수 × 50분으로 바꾸지 않았다.

## 기록

`activity`는 배정, 수락, 거절, 수행, 종료만 시연 조작 때 쌓는다. 초기 가짜 기록은 없다. 최근 5건을 보여주고 전체는 모달이다. 브라우저 메모리만 사용하므로 새로고침하면 사라진다. 초기화해도 빈다.

## 접근 범위

근무조 리더와 응급전문간호사는 전체 환자와 배정 버튼을 본다. 개별 간호사는 본인 환자만 펼치고, 수락한 지원 대상만 추가로 본다. 동료는 이름, 단계, 담당 업무량만 보인다.

## 간호부 확인이 필요한 항목

1. 인력 기준을 담당 간호사 1명당 50분으로 둘지, 환자 1명당 50분으로 바꿀지.
2. 확인중 처방의 표준시간을 담당 업무량에 남길지.
3. 50분 경계와 30분 경계를 발표에서 임상 기준으로 말해도 되는지. 지금은 시연 경계다.
4. 수락 후 업무량을 60%로 줄이는 계수 0.4와 하한 0.35를 유지할지.
5. 09:00 지원 알림이 지연 2단계 없이 높음 1단계 두 건인 구성이 발표에 맞는지.
6. 지원 종료 기록의 최소 5분이 같은 시각에 끝내도 표시되는 점을 설명할지.
